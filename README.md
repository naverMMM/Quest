# QUEST · 오늘의 모험

일상의 작은 실천을 기록하는 중세 판타지 MMORPG풍 HUD 프로토타입입니다. 외부 패키지, CDN, API 키 없이 실행됩니다.

2026-10-29 확인한 `main` (`4d077c51b05b002a8256b428b880d4943b2df985`)에는 `README.md`만 있었습니다. 다른 브랜치나 실행 가능한 UI 소스가 없었으므로, 이 변경은 기존 앱 리팩터링이 아닌 요구사항에 따른 **신규 실행형 프로토타입**입니다. 이전 대화의 화면 및 기능을 복구한 것으로 해석하면 안 됩니다.

## 실행

Node.js 20 이상에서:

```sh
npm start
```

`http://localhost:3000`을 엽니다. `PORT=4173 npm start` 또는 `npm run dev -- --port 4173`으로 포트를 지정할 수 있습니다. 설치와 빌드가 필요 없습니다. 정적 호스팅에서는 `public/`을 루트로 제공하면 됩니다. ES 모듈을 사용하므로 파일을 직접 더블클릭하는 대신 HTTP 서버로 실행하세요.

## 화면과 동작

- 성채·강·숲을 그린 자체 SVG 배경, 밝은 세이지·청록·금색 팔레트
- 원형 모험가 문장, 레벨 배지, 경험치 HUD, 원형 지역 지도
- 종이 질감의 단일 모험 기록과 행 형태 퀘스트, 원형 완료 버튼
- 고정된 원형 하단 메뉴: 퀘스트 / 모험가 / 가방 / 업적 / 세계 지도
- 부유 입자, 화면 진입, 메뉴 호버, 보상 반응, 경험치 전환
- 직접 퀘스트 생성, 상세 보기, 필터, 완료 보상, 100 EXP마다 레벨업
- 로컬 저장, 현지 날짜 기준 일일 퀘스트 갱신, 설정에서 기록 초기화
- 반응형 레이아웃, 키보드 조작, 기본 dialog 포커스 관리, 동작 줄이기 지원

## 범위와 데이터

기록은 브라우저 `localStorage`에 저장됩니다. 로그인, 서버 동기화, 멀티플레이, 상점, 결제는 없습니다. 지도는 세계관 일러스트입니다. 골드는 현금 가치가 없는 게임 포인트입니다. 매일 기본 퀘스트 3개로 갱신되며 직접 만든 퀘스트도 사라집니다. 누적 경험치·골드·완료 횟수와 움직임 설정은 유지됩니다. 레벨 10에는 칭호가 바뀌며 직업 시스템은 구현하지 않았습니다. 같은 브라우저의 다른 탭 변경은 반영하지만 동시 완료를 서버 트랜잭션처럼 보장하지 않습니다.
